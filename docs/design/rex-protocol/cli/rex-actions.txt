$ rex actions --help
List the actions that a client or the server offers.

With -C or REX_CLIENT, this lists the actions that client offers, as it most
recently reported them to the server. Otherwise it lists the actions the server
offers: those that init.lua defines with rex.action, followed by those of every
block type. A key binding can name any action in either list.

The ARGS column lists each action's arguments. An argument followed by ? is
optional.

Examples:
  rex actions
  rex -C studio actions
  rex actions --json

Usage:
  rex actions [flags]

Options:
      --json  output actions as JSON
  -h, --help  help for actions

Global options:
  -S, --server SERVER     connect to SERVER, a host's label or a server address (a value with a port is always an address)
  -C, --client CLIENT     act on client CLIENT, given as a label or ID
      --autostart         start a missing local server (default true)
      --timeout DURATION  limit each connection and nonstreaming request to DURATION (default 10s)
      --color WHEN        set color WHEN to auto, always, or never (default auto)
  -v, --verbose count     increase diagnostic verbosity (repeatable)
