$ rex api --help
Inspect and call methods exposed by the server's control API.

Use call to run a method by name. Use list to discover the methods exposed by
the connected server, including methods provided by block creators. Use describe
to read one method's schemas, examples, and validation rules.

Examples:
  rex api call server.status
  rex api call -s work session.view
  rex api list
  rex api describe session.new_split

Usage:
  rex api [command] [flags]

Commands:
  call      Call a server API method
  list, ls  List server API methods
  describe  Describe a server API method

Options:
  -h, --help  help for api

Global options:
  -S, --server SERVER     connect to SERVER, a host's label or a server address (a value with a port is always an address)
  -C, --client CLIENT     act on client CLIENT, given as a label or ID
      --autostart         start a missing local server (default true)
      --timeout DURATION  limit each connection and nonstreaming request to DURATION (default 10s)
      --color WHEN        set color WHEN to auto, always, or never (default auto)
  -v, --verbose count     increase diagnostic verbosity (repeatable)
