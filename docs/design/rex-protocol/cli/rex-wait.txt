$ rex wait --help
Wait for a block, window, or session to end.

For a terminal block, wait returns the child process's exit status. It does not
wait for the block itself to close, so it also works with terminals created with
--keep-open. Waiting for any other block, a window, or a session succeeds when
that resource closes or is destroyed. If a terminal closes before reporting a
child exit, wait returns 1. A block that closes before wait starts watching it
also returns 1, because Rex can no longer tell what kind of block it was.

By default, wait runs until the target ends or the server disconnects. Use --for
to limit the wait. The global --timeout still limits connections and individual
API requests, but it does not limit event delivery. With --json, the command
writes the payload that ended the wait as one line of JSON.

If Rex cannot determine a terminal child's exit status, wait returns 1. Statuses
above 255 are reduced modulo 256 to match shell behavior.

Targets may be IDs, labels, ID suffixes, or a window's one-based position. If a
target matches more than one resource kind, use a full ID to select the intended
resource.

Examples:
  rex wait c2a9f3
  rex wait build
  rex wait 2 -s work
  rex wait --for 10m $B || echo timed out

Usage:
  rex wait TARGET [flags]

Options:
  -s, --session string  scope to session SESSION
  -w, --window string   scope to window WINDOW
      --for DURATION    give up after DURATION
      --json            output the terminating payload as JSON
  -h, --help            help for wait

Global options:
  -S, --server SERVER     connect to SERVER, a host's label or a server address (a value with a port is always an address)
  -C, --client CLIENT     act on client CLIENT, given as a label or ID
      --autostart         start a missing local server (default true)
      --timeout DURATION  limit each connection and nonstreaming request to DURATION (default 10s)
      --color WHEN        set color WHEN to auto, always, or never (default auto)
  -v, --verbose count     increase diagnostic verbosity (repeatable)
