$ rex session move --help
Move a session to a new place in the session order.

The session order is the order that session ls prints. It also decides which
session a number names, so after a move, "rex session inspect 1" shows whichever
session is now first.

Exactly one of --before, --after, or --index is required. Positions count from
one. An index past the end moves the session last. Moving a session to where
it already is does nothing and succeeds.

If SESSION is omitted, Rex uses REX_SESSION when it is set. Otherwise, Rex uses
the default session.

Examples:
  rex session move logs --before work
  rex session move 3 --after 1
  rex session move --index 1
  rex session move build --index 99

Usage:
  rex session move [SESSION] (--before S | --after S | --index N) [flags]

Options:
      --before S  move immediately before session S
      --after S   move immediately after session S
      --index N   move to one-based position N
  -h, --help      help for move

Global options:
  -S, --server SERVER     connect to SERVER, a host's label or a server address (a value with a port is always an address)
  -C, --client CLIENT     act on client CLIENT, given as a label or ID
      --autostart         start a missing local server (default true)
      --timeout DURATION  limit each connection and nonstreaming request to DURATION (default 10s)
      --color WHEN        set color WHEN to auto, always, or never (default auto)
  -v, --verbose count     increase diagnostic verbosity (repeatable)
