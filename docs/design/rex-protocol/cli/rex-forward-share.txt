$ rex forward share --help
Forward a port on the server to a target that this machine can reach. This is
rex forward new -R for the common case of one forward.

The target is a URL, such as http://localhost:3000, or host:port, or a port,
which means that port on this machine's localhost. URLs without a port are
read as for rex forward open.

The forward listens on the server on --bind and --port, by default 127.0.0.1
and a free port. Use --bind '*' to let other machines connect to it. Once it
listens, rex forward share prints where: the target's URL with its host and
port changed, if the target is a URL, or else host:port. With --bind '*' the
host is the server's, as rex reached it.

Clients address what they send to the server rather than to the target's own
name, so a site that checks the Host header, or that serves https with a
certificate for its own name, may not work through the forward.

rex forward share runs in the foreground like rex forward new, until it is
interrupted or the forward is closed with rex forward close.

Usage:
  rex forward share [flags] (URL | [host:]port)

Options:
  -b, --bind ADDRESS    listen on ADDRESS; * means every interface (default 127.0.0.1)
  -p, --port PORT       listen on PORT; 0 picks a free port
  -s, --session string  keep the forward's block in session SESSION
  -h, --help            help for share

Global options:
  -S, --server SERVER     connect to SERVER, a host's label or a server address (a value with a port is always an address)
  -C, --client CLIENT     act on client CLIENT, given as a label or ID
      --autostart         start a missing local server (default true)
      --timeout DURATION  limit each connection and nonstreaming request to DURATION (default 10s)
      --color WHEN        set color WHEN to auto, always, or never (default auto)
  -v, --verbose count     increase diagnostic verbosity (repeatable)
