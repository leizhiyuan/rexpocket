$ rex capture --help
Print the screen and scrollback of a terminal block.

When --block is omitted, Rex uses REX_BLOCK if it names a live block. Otherwise,
it uses the focused block of the default window. Text is the default format.
HTML preserves rendered styling. VT preserves terminal control sequences. Output
always ends with a newline.

A terminal keeps about 64 MiB of scrollback. That is roughly 100,000 lines of
plain text at 80 columns, and fewer in a wider terminal or with styled output.
Once the limit is reached, the oldest lines are dropped.

Examples:
  rex capture
  rex capture -b logs --trim > screen.txt
  rex capture --format=html > screen.html
  rex capture -s build -w 2

Usage:
  rex capture [flags]

Options:
  -b, --block BLOCK     select block BLOCK
  -s, --session string  scope to session SESSION
  -w, --window string   scope to window WINDOW
      --format FORMAT   output FORMAT: text, html, or vt (default text)
      --trim            remove trailing blank lines
      --unwrap          join soft-wrapped lines
  -h, --help            help for capture

Global options:
  -S, --server SERVER     connect to SERVER, a host's label or a server address (a value with a port is always an address)
  -C, --client CLIENT     act on client CLIENT, given as a label or ID
      --autostart         start a missing local server (default true)
      --timeout DURATION  limit each connection and nonstreaming request to DURATION (default 10s)
      --color WHEN        set color WHEN to auto, always, or never (default auto)
  -v, --verbose count     increase diagnostic verbosity (repeatable)
